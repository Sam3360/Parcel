# Example packages

| File | Shows |
|---|---|
| `minimal.parcel` | The smallest useful package: two files. |
| `research-collection.parcel` | Nested folders, a Markdown note attached to a file, a link entry, a categorised reference, entry and external dependencies, workspace notes. |

Inspect them with any ZIP tool, or with the CLI:

```powershell
parcel inspect examples\research-collection.parcel
parcel verify  examples\research-collection.parcel
```

They are generated by `cargo run -p parcel-workspace --example make_examples -- examples` and verified by an automated test, so they always match the current format.
